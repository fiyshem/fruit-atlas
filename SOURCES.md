# Reference directions (project notes)

The dataset is a curated educational index with generated editorial form guides. It should not be interpreted as a full cultivar registry, a clinical nutrition database or a definitive taxonomic checklist.

For deeper verification of individual records, use regionally relevant botanical and horticultural references such as:

- Fruit and Nut Cultivars Database / American Pomological Society: https://www.fruitandnutlist.org/
- Global Biodiversity Information Facility (GBIF): https://www.gbif.org/
- USDA FoodData Central: https://fdc.nal.usda.gov/
- Food and Agriculture Organization: https://www.fao.org/
- Wikipedia REST API image resolution: https://en.wikipedia.org/api/rest_v1/

Learning-library pages each use a distinct primary Unsplash photograph; they intentionally do not replace an individual photo with a repeated generic fallback. These image endpoints are external and are not included in the ZIP as local media files.

The main Dragon fruit species profile uses the public-domain photograph [Dragon fruit.JPG](https://commons.wikimedia.org/wiki/File:Dragon_fruit.JPG), a real dragon fruit plant with fruit. The profile avoids the unrelated English Wikipedia page titled “Dragon.”


Learning-library imagery: each guide has an explicit image assignment in `data/guide-images.json`. The guide images use unique Unsplash photo IDs across the guide set; the flavour/cooking section uses fruit- and food-oriented imagery rather than the earlier landscape-only set. Guide pages do not use a repeated generic fallback.
